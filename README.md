# projeto-integrador-frontend-elis-regina
## Projeto integrador de Frontend para Web - ADS
Este projeto consiste na criação de um portfólio profissional desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas.
O site tem como objetivo apresentar minha trajetória profissional, projetos, habilidades e conhecimentos na área de tecnologia.
O projeto será desenvolvido utilizando HTML.
